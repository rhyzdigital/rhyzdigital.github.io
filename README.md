# RHYZ Digital Website

Official static website for **RHYZ Digital**.

> Business Software. Built to Last.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

No build process or package installation is required.

## Open in WebStorm

1. Clone this repository:
   ```bash
   git clone https://github.com/rhyzdigital/rhyzdigital.github.io.git
   ```
2. Open WebStorm.
3. Select **Open** and choose the cloned folder.
4. Right-click `index.html`.
5. Choose **Open in Browser**.

## Deploy to GitHub Pages

The repository must be named exactly:

```text
rhyzdigital.github.io
```

Push the files to the `main` branch:

```bash
git add .
git commit -m "Launch RHYZ Digital website"
git push origin main
```

Then open:

```text
https://rhyzdigital.github.io
```

If the site does not appear immediately:

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save and wait a few minutes.
